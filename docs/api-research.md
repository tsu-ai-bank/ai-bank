# Исследование API hh.ru

## 1. Аутентификация и лимиты
* **нужна ли регистрация приложения и токен:** Если не передан токен авторизации, то после первого запроса будет предложено пройти капчу. \
  Для получения token нужно:\
  Шаг 1. Регистрация компании на hh.ru\
  Шаг 2. Регистрация приложения на dev.hh.ru\
  Шаг 3. Реализация OAuth 2.0 авторизации в коде
* **Лимиты (Rate Limits):** Около 30 запросов в секунду.
Максимальное количество выдаваемых вакансий на один поисковый запрос — 2000 штук (глубже hh.ru просто не пустит, даже если пишет, что найдено 50 000).\
нужно будет дробить по дате публикации для получения всех вакансий в случае необходимости.
* **Как отфильтровать Томскую область:** указать параметр area=1255
* **Обязательные заголовки:** `User-Agent` (hh.ru требует информативный User-Agent, часто с контактами разработчика).

## 2. Эндпоинт: Поиск вакансий (`/vacancies`)
* **URL:** `https://hh.ru`
* **Критические параметры:** `text`, `area`, `per_page`, `page`.
* **Что реально приходит (структура ответа):**
  https://api.hh.ru/openapi/redoc#tag/Poisk-vakansij/operation/get-vacancies \
  (по этой ссылке можно и узнать и другую информацию) \
  вроде хранится вся нужная инфа
